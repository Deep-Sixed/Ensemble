# Repo Audit Skill

Use this checklist for repository orientation.

- Identify the stack, entrypoints, package managers, and runtime versions.
- Check git branch, remote, dirty state, and recent commits.
- Read README, architecture docs, and manifests before making assumptions.
- Run lightweight validation before heavy services.
- Separate environment/setup failures from code failures.
- Summarize risks, blockers, and next actions.
